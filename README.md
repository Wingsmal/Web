# Система учета тренировок (Express + EJS)

Веб-приложение для управления каталогом тренировок. Проект разработан в рамках практического занятия для демонстрации работы с шаблонизатором **EJS**, базой данных **PostgreSQL** (через ORM Sequelize) и концепцией **Middleware** в Express.js.

## 🚀 Основной функционал

*   **Server-Side Rendering (SSR):** Генерация динамических HTML-страниц на сервере с помощью EJS (использование partials для шапки и подвала).
*   **Имитация авторизации:** Доступ к добавлению тренировок защищен middleware (требуется параметр `?auth=1` в URL).
*   **Логирование в БД:** Кастомный middleware перехватывает каждый запрос к серверу и сохраняет метод, URL и время в специальную таблицу `Logs` в базе данных.
*   **Кастомная обработка ошибок:** Отдельные middleware для перехвата и красивого отображения ошибок 404 (Не найдено) и 500 (Внутренняя ошибка сервера).
*   **Безопасность и Валидация:** Защита на уровне контроллера от сохранения пустых строк, пробелов и отрицательных числовых значений.
*   **Имитация сбоев:** Наличие специального маршрута и кнопки для принудительной генерации ошибки 500 для тестирования обработчиков.

## 🛠 Технологии

*   **Node.js** & **Express**
*   **EJS** (Шаблонизатор)
*   **PostgreSQL** & **Sequelize** (БД и ORM)
*   **Bootstrap 5** (Стилизация интерфейса)

## 📦 Установка и запуск

### 1. Подготовка
Убедитесь, что у вас установлены Node.js и PostgreSQL. Создайте пустую базу данных в Postgres (например, `workout_db`).

### 2. Установка зависимостей
Склонируйте репозиторий и установите пакеты:
```bash
npm install
```

### 3. Настройка базы данных
Откройте файл `config/config.json` и укажите данные для подключения к вашей локальной базе данных (username, password, database).

### 4. Миграции и Сиды
Создайте таблицы в базе данных и наполните их начальными данными:
```bash
npx sequelize-cli db:migrate
npx sequelize-cli db:seed:all
```

### 5. Запуск сервера
Запустите приложение командой:
```bash
node server.js
```
Сервер будет доступен по адресу: `http://localhost:3000/`

## 🧪 Как тестировать функционал?

1.  **Авторизация:** Перейдите на `http://localhost:3000/workouts` (кнопка добавления скрыта). Нажмите "Войти в систему" (в URL добавится `?auth=1`), после чего откроется полный доступ.
2.  **Ошибка 404:** Введите несуществующий адрес, например `http://localhost:3000/qwerty`.
3.  **Ошибка 500:** Нажмите красную кнопку "Вызвать 500" на главной странице.
4.  **Валидация:** Попробуйте добавить тренировку с отрицательной длительностью или пустым именем.
5.  **Логи:** Откройте вашу базу данных через pgAdmin или DBeaver и проверьте таблицу `Logs` — там будут зафиксированы все ваши переходы по сайту.
